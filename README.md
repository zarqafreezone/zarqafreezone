# 🛃 تطبيق المنطقة الحرة الزرقاء — Zarqa Free Zone

منصة إعلانات (بيع/شراء) بلا جمارك، ثنائية اللغة (عربي/إنجليزي)،
مع قاعدة بيانات مركزية، محادثات مباشرة، صور، إشعارات، بوابة دفع، ولوحة تحكم.

> جميع الحقوق محفوظة: **شبكة نشوان للتسويق**

---

## 📁 محتويات المشروع
```
├── server.js            الخادم (Node خالص بدون مكتبات) + REST API + قاعدة البيانات
├── package.json         بيانات المشروع
└── public/              واجهة التطبيق (تُخدَم كملفات ثابتة)
    ├── index.html
    ├── css/styles.css
    ├── images/          صور حقيقية من المنطقة الحرة الزرقاء
    └── js/
        ├── data.js      التصنيفات + البيانات التجريبية (هنا تُضاف التصنيفات الجديدة)
        ├── i18n.js      نظام اللغتين (عربي/إنجليزي) + القواميس
        ├── store.js     طبقة الاتصال بقاعدة البيانات المركزية (API)
        └── app.js       منطق الواجهة (الصفحات، الإدارة، المحادثات، الدفع)
```

عند التشغيل تُنشأ تلقائياً:
- `db.json` — قاعدة البيانات المركزية (مستخدمون، إعلانات، مفضلة، بنرات، مدفوعات)
- `chat.json` — سجل المحادثات
- `public/uploads/` — صور الإعلانات والمحادثات المرفوعة

---

## 🚀 التشغيل محلياً
المتطلبات: **Node.js 18+**
```bash
node server.js
```
ثم افتح المتصفح على: `http://localhost:8000`

---

## 🛠️ الإدارة (لوحة تحكم المدير)
1. اضغط أيقونة ⚙️ في الشريط العلوي.
2. كلمة المرور الافتراضية: **`admin123`**

**ما يمكنك إدارته:**
| التبويب | الوظائف |
|---|---|
| الإعلانات | تمييز إعلان (⭐) / إلغاء / حذف |
| المستخدمون | تقييم النجوم (1-5) / توثيق ✔ / حذف |
| الإعلانات المدفوعة | تعديل نصّي البنرين (عربي+إنجليزي) / تفعيل وإيقاف |
| الإحصائيات | عدد الإعلانات، المستخدمين، المميّزة، الإيرادات |

**تغيير كلمة مرور المدير عند النشر:**
```bash
ADMIN_PASSWORD=كلمة_سر_قوية node server.js
```

## 🗂️ إضافة / تعديل التصنيفات
كل التصنيفات في ملف واحد: **`public/js/data.js`** داخل المصفوفة `CATEGORIES`.

الهيكل الهرمي:
```js
{
  id: "vehicles",              // معرّف فريد (إنجليزي)
  name: "مركبات",              // الاسم بالعربية
  icon: "🚗",                  // رمز تعبيري
  color: "#2563eb",
  subs: [                      // التصنيفات الفرعية
    {
      id: "cars", name: "سيارات", icon: "🚙",
      types: ["سيدان", "دفع رباعي SUV", ...],   // الأنواع
      brands: ["تويوتا", "هيونداي", ...]        // الماركات
    }
  ]
}
```

**مثال: إضافة صنف «المعدات الزراعية» تحت المركبات** — أضِف داخل `subs`:
```js
{ id:"agri", name:"معدات زراعية", icon:"🚜",
  types:["جرار زراعي","حصادة","محراث","أخرى"], brands:["جون دير","ماسsey فيرغسون","أخرى"] }
```
ثم أضِف الترجمات الإنجليزية في **`public/js/i18n.js`** داخل القاموس `DICT`:
```js
"معدات زراعية":"Agricultural Machinery",
"جرار زراعي":"Tractor", ...
```
أعد تحميل الصفحة — وسيظهر التصنيف الجديد فوراً في كل مكان. ✨
*(أنا أستطيع فعل ذلك لك في أي وقت — فقط اطلب التصنيف المطلوب.)*

## 📱 التحويل إلى تطبيق جوال (أندرويد/آيفون) لاحقاً
التطبيق جاهز للتغليف بإطار **Capacitor** (نفس الكود لكلا الهاتفين):
1. ثبت: `npm i @capacitor/core @capacitor/cli @capacitor/android @capacitor/ios`
2. `npx cap init "Zarqa Free Zone" com.nashwan.zarqafz --web-dir=public`
3. `npx cap add android` (وللآيفون `npx cap add ios` — يتطلب Mac + Xcode)
4. `npx cap copy` ثم افتح المشروع في Android Studio / Xcode
5. أشِر واجهة التطبيق إلى رابط الخادم المنشور.

> 💡 يُنصح أولاً بتفعيل **PWA** (manifest + service worker) ليكون قابلاً للتثبيت من المتصفح مباشرة على الهاتفين.

## 🌐 النشر (deployment) للحصول على رابط دائم
أبسط خيار مجاني: **Render** أو **Railway**
1. ارفع المشروع إلى GitHub.
2. أنشئ Web Service يشير إلى المستودع.
3. أمر التشغيل: `node server.js` ، المنفذ: `8000` (أو `PORT`).
4. أضِف متغيرات البيئة (ADMIN_PASSWORD، مفاتيح Stripe إن وُجدت).
5. ستحصل على رابط HTTPS ثابت مثل `https://zarqa-fz.onrender.com`.

## 🔐 الأمان عند النشر (مهام مقترحة)
- فعّل **OTP حقيقي عبر SMS** (Twilio/Vonage) بدل الرمز التجريبي `1234`.

- أضِف تحديد معدّل الطلبات (rate limiting) على نقاط الـ API.
